## JS vocabulary, stage 4 of 10

Fourth rung -- the bulk of JS's own `Math` object, everything beyond
the basic arithmetic from `v0.061`. `random_int` is deliberately
excluded from this stage; it isn't a pure function of its inputs, so
it ships later (`v0.070`) with its own design exception rather than
folded in here.

### What's planned

- `absolute`, `ceiling`, `floor`, `truncate_number`, `sign`, `sqrt`,
  `cbrt`, `power`, `exp`, `log`, `log2`, `log10`, `hypot`, `clamp`,
  `average`/`mean`, `median`, `gcd`, `lcm`, `percentage_of`,
  `to_fixed`, `to_precision`

## `arklight search --retrieve-doc`

A new mode on the existing `arklight search` subcommand that switches
it from component-schema lookup into doc-tree retrieval: bare
`--retrieve-doc` prints the root `docs/README.md`; a folder flag
(`--foundational`, `--proposals`, ...) prints that folder's own
`README.md` index; adding `--file NAME` appends one file's full
contents. Read-only and unsynthesized -- exact file bytes, nothing
invented or summarized.

### What's planned

- The `--retrieve-doc` mode switch, mutually exclusive with the
  existing `name` positional and `--serve`.
- Seven directory flags, one per `docs/` lifecycle folder.
- `--file NAME`, scoped to a preceding directory flag, with
  case-insensitive stem matching and a `difflib`-based "did you mean"
  on a miss.
