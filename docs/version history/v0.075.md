## What's planned

- Record build results (success/failure) into `.arklight/`.
- Associate each recorded result with whatever source/repository
  identity is available from the Git provider.
- Store compiler version and timestamp alongside each result.

This is compiler-owned build history, distinct from Git history --
Git knows what changed in the repository; this stage lets ARKlight
know what happened the last time it tried to build that state.
