## JS vocabulary, stage 5 of 10

Fifth rung -- the bulk of JS's own `String.prototype`, beyond the
casing helper from `v0.062`. `replace_first`/`replace_all` ship with
a hard requirement, not a suggestion: a literal substring argument
only, never a regex pattern string passed through `new RegExp(...)`.

### What's planned

- `capitalize`, `title_case`, `trim_start`, `trim_end`, `pad_start`,
  `pad_end`, `repeat`, `slice_string`, `char_at`, `replace_first`,
  `replace_all`, `split_count`, `reverse_string`, `string_length`,
  `includes_substring`, `starts_with`, `ends_with`, `is_empty`

## `Provider`, stage 1 of 6: the contract itself

The barebones interface a site can use to declare it talks to an
external service at runtime (Firebase was the motivating example, but
the contract is vendor-neutral) -- an interface only, no vendor code,
no networking code, shipped in ARKlight's core. Gated as an
experimental feature from the start, the same way `css-media-queries`
or `raw-postprocess` are.

### What's planned

- `Provider.declare(name=..., capabilities=[...])`, with `capabilities`
  validated against a closed vocabulary (finalized in stage 6).
- A new `provider-integration` entry in `arklight/experimental.py`'s
  `FEATURES` dict, following the existing three-step registration
  process.

## Rei, the compiler narrator

An opt-in `--narrate` flag on `arklight build`, sibling to the
existing `--verbose`/`--debug`: instead of `[ARKlight] ...` stage
lines, prints the same pipeline progress as short natural-language
sentences. A new `rei` section in `arklight.config.py` lets a project
pin its own default log mode (`plain`/`verbose`/`narrate`) instead of
passing a flag on every build. Pure Python, deterministic, no JSON,
no network, no LLM -- see
[`docs/Proposals/REI-COMPILER-NARRATOR-PROPOSAL.md`](../Proposals/REI-COMPILER-NARRATOR-PROPOSAL.md)
for the full design and
[`docs/Implementation/REI-COMPILER-NARRATOR-ADDENDUM.md`](../Implementation/REI-COMPILER-NARRATOR-ADDENDUM.md)
for the implementation plan.

### What's planned

- `--narrate` on `arklight build`, mutually exclusive with
  `--verbose`/`--debug`.
- `rei.default_mode` config key (`"plain"`/`"verbose"`/`"narrate"`).
- One-time introduction banner (Rei's greeting + resolved config) on
  the first build into a missing-or-empty output directory; skipped
  on subsequent builds into the same output directory.
- On an unknown-component-type or required-prop schema violation
  specifically, narration appends one fixed line pointing at the
  existing `arklight search <name>` lookup -- not a hint Rei
  generates herself, and not extended to other validation-error
  categories (state/action/behavior registries).
