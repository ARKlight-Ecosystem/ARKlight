# v0.003 -- JavaScript helpers (+ two vocabulary addenda)

Adds a closed, fixed vocabulary of client-side behaviors -- no
arbitrary JavaScript is ever accepted from user code -- and grows the
component vocabulary from the original v0.001 core to roughly 79
components.

## What shipped

- A JS backend generating a static `arklight.js`: a fixed set of
  behaviors (`toggle`, `scroll-to`, `copy`, `dismiss`) plus automatic
  current-page nav-link highlighting.
- `on_click` / `behavior_target` / `toggle_class` props on any
  component, validated at build time and rendered as `data-ark-*`
  attributes.
- A generic `aria_*` prop convention, `role`/`tabindex`, and a
  `for_`/`html_for` alias for `<label for>`.
- Intrinsic responsive layout utility classes (`.stack`, `.cluster`,
  `.sidebar`, `.switcher`, `.grid`, `.center`, `.reel`,
  `.fluid-heading`) built from flexbox/grid alone, no `@media` query
  needed.

## Vocabulary addendum 1

Semantic layout (`Header`, `Footer`, `Main`, `Nav`, `Section`,
`Article`, `Aside`, `Figure`/`FigCaption`, `Details`/`Summary`),
text-level semantics (`Strong`, `Em`, `Code`, `Cite`, `Time`, ...),
forms (`Form`, `Input`, `Textarea`, `Select`, ...), tables, and media
(`Video`, `Audio`, `Source`) -- 46 new components in total.

## Vocabulary addendum 2 ("even more vocabulary")

Numbered/description lists, art-directed responsive images
(`Picture`/`PictureSource`), native zero-JS widgets (`Progress`,
`Meter`, `Datalist`, `Output`, `Dialog`), bidi and ruby text
semantics, table column grouping, video/audio captions, image maps,
`IFrame` embeds, and a `NoScript` fallback -- 33 more components.

All of this is additive data in `arklight.ir.schema.SCHEMA`; none of
it touches `normalize.py`, `validate.py`, or `build.py`.
