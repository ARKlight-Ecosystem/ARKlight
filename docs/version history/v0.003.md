# v0.003 -- JavaScript helpers + two vocabulary addenda

Closed-behavior JS backend, plus a large expansion of the component
vocabulary beyond the original 9 -- semantic layout, forms, tables,
media, and text-level semantics, all mapped straight to standard HTML
tags.

## What shipped

- The JS backend (`arklight/backend/js/`) -- named, closed behaviors
  only, never an arbitrary script string.
- ~79 new components across two vocabulary-extension addenda: semantic
  sectioning (`Header`/`Nav`/`Section`/...), forms (`Form`/`Input`/
  `Select`/...), tables, media embeds, and more.

This is the release that turned ARKlight from "9 components" into
"most of what a static site actually needs," while keeping every new
name in the same closed, validated schema the first 9 already used.
