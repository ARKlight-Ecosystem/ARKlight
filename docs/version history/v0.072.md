Second rung -- the shape of Project Knowledge inside the compiler,
still with no external provider wired in.

## What's planned

- The internal Project Knowledge abstraction, made available through
  compiler context.
- The providers/facts/observations separation: providers answer
  questions using information already available to the compiler;
  facts are what a provider directly establishes; observations are
  conclusions the compiler derives from multiple facts.
- Keeping facts and observations distinguishable, so a provider's
  raw output never gets silently reinterpreted as compiler-derived
  knowledge.

No provider (Git or otherwise) is connected yet -- that's `v0.073`.
This stage is deliberately just the concept, so later providers plug
into an abstraction that already exists rather than each inventing
its own shape.
