# v0.041 -- CLI/pipeline/JS runtime hardening + stateful JS addenda I & II

A maintenance-and-completeness pass: better error handling throughout
the CLI/pipeline/JS runtime, plus two more `Action.*` helpers that
real state-driven sites kept reaching for.

## What shipped

- CLI/pipeline/JS runtime error-handling hardening (catch-all error
  handling, `arkNotify()`, guarded file writes).
- `Action.decrement`/`Action.reset` (addendum I) and
  `Action.append`/`Action.remove` (addendum II) -- the `-1` counterpart
  to `increment`, "put state back the way it started" without
  hardcoding the initial value again, and list-valued state mutation.
