# v0.037 -- Sealed ARK Bundles

`.ark` bundles are now encrypted by default -- `arklight unpack` to
get a sealed bundle's contents back out, with `assets/` and every
other file carried over intact.

## What shipped

- Archive-half sealing (`arklight/packer/seal.py`), on by default.
- `arklight unpack`.

This sealing/unsealing format is also what the Android backend's
`.ark`-bundle viewer (`ArkBundle.kt`/`ArkSeal.kt`, evolved from the
existing `ARKlight-Viewer-for-Android-Devices` app) mirrors on the
Kotlin side -- see `docs/Backends/ANDROID-BACKEND-IMPLEMENTATION.md`.
