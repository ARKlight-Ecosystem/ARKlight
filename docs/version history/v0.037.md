# v0.037 -- Sealed ARK Bundles

`.ark` bundles are now encrypted by default, and assets are carried
into the archive.

## What shipped

- `arklight pack` now seals the archive half by default. Without
  `--passphrase`, a random embedded key travels with the bundle
  (blocks generic archive tools, not a secret from ARKlight itself);
  with `--passphrase`, the key is derived via PBKDF2-HMAC-SHA256 and
  never stored, for real confidentiality.
- `--plain` flag opts back into the original v0.036 plain-ZIP
  behavior.
- `arklight unpack <bundle.ark> -o OUTPUT_DIR [--passphrase ...]` --
  new CLI subcommand reversing `pack()`, auto-detecting sealed vs.
  plain bundles.
- `assets/` (and any other non-html/css/js file) is now carried into
  the archive, closing the scope gap left open in v0.036.
