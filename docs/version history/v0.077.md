## What's planned

  failing state.
- Correlate repository changes (from the Git provider) with build
  transitions.

This is the "observations" layer of the Project Knowledge model:
conclusions ARKlight derives from multiple stored facts, kept
distinguishable from the raw facts themselves so provider-specific
detail never becomes mysterious compiler behavior.
