# v0.067 -- JS vocabulary: list-scalar derivations catalog

**Status: PLANNED -- not yet started.** Forward-looking summary,
written ahead of implementation as part of staging
[`docs/Implementation/JS-VOCABULARY-ADDENDUM-v0.070.md`](../Implementation/JS-VOCABULARY-ADDENDUM-v0.070.md)

Seventh rung -- reduces a list-typed `State` value to a scalar the
way `sum`/`count` already reduce multiple *named* states. Still
scalar-out, so it fits today's `DERIVATION_REGISTRY` as-is; the
list-in/list-out sort/filter registry these read like siblings of
stays out of scope for this ladder (Tier 3, still an open proposal).
