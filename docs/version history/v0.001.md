# v0.001 -- Python -> HTML

The first working slice of the compiler pipeline: write a site as
plain Python function calls (`Page`, `Heading`, `Text`, `Button`,
`Container`, `Link`, `Image`, `List`, `Item`), run `arklight build
site.py`, get plain, dependency-free `index.html` out.

## What shipped

- The full pipeline shape every later milestone builds on: Python
  Source -> Python AST -> ARK AST -> Normalization -> Validation ->
  Website IR -> Backend Interface -> HTML output.
- The first 9 built-in components and their schema entries.
- Build-time validation instead of silent-wrong-in-the-browser
  failures -- ARKlight's core "beginner friendly" guarantee from
  day one.

See [`docs/Foundational/ARCHITECTURE.md`](../Foundational/ARCHITECTURE.md)
for the pipeline diagram as it stands today.
