# v0.001 -- Python -> HTML

First working compiler pipeline: a Python site file compiles all the
way to static HTML files, matching the pipeline described in
[`ARCHITECTURE.md`](../Foundational/ARCHITECTURE.md).

## What shipped

- A public component API: `Site`, `Page`, `Heading`, `Text`,
  `Button`, `Container`, `Link`, `Image`, `List`, `Item`.
- A site file is plain Python -- discovered and loaded via the
  stdlib `ast` module, then executed in isolation to produce a live
  `Site` object.
- Normalization (flattening nested list children, dropping
  `None`/`False`, auto-wrapping bare strings as `Text`) and
  validation (schema-checked component types, required props,
  text-only nesting rules) against a single shared schema.
- A first backend: HTML, mapping components to tags, handling
  heading levels, prop-to-attribute mapping, and route-to-file-path
  mapping.
- CLI: `arklight build <entry.py> [-o OUTPUT_DIR]`, `arklight
  --version`.
- An example site (`examples/hello_site/site.py`) with two pages,
  and 42 tests covering every stage.

## Notable fixes along the way

- Text-only components (like `Heading`) no longer double-wrap plain
  strings.
- Errors raised inside a page function now surface as a clear
  `CompileError` instead of a raw traceback.
