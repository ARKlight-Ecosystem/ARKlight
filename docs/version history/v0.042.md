# v0.042 -- Extra CSS features + CLI discoverability

Two smaller initiatives, scoped out of what became `v0.048`: cutting
boilerplate in styling that already sort of existed, plus closing two
CLI-discoverability gaps.

## What shipped

- `Site.style(name, rules)` -- custom CSS class authoring, rendered as
  real `.name { prop: value; }` blocks after the base stylesheet.
- `arklight search <name>` -- read-only component-schema lookup, with
  typo-tolerant "did you mean...?" suggestions when there's no exact
  match.
- `arklight --help` / bare `arklight` now print help text instead of a
  terse argparse error.
