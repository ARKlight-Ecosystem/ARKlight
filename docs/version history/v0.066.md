## JS vocabulary, stage 6 of 10

Sixth rung -- `Show`'s common `v-if`-equivalent guards, beyond the
comparison predicates from `v0.062`.

### What's planned

- `and`, `or`, `not`, `in_range`, `one_of`, `is_empty`/
  `is_not_empty`, `is_null`

## `Provider`, stage 2 of 6: IR and validation integration

Threads a declared `Provider` through the compiler pipeline the same
way `site.media_query(...)` already threads its own experimental
config through `WebsiteIR`.

### What's planned

- A declared `Provider` recorded on `Site`, alongside
  `custom_media_queries`/`raw_postprocessors`.
- `arklight/ir/validate.py` enforcing the closed capability vocabulary
  at build time -- an unknown capability fails the build the same way
  an unknown prop does elsewhere in the schema.
