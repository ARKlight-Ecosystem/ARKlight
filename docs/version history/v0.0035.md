# v0.0035 -- Stateful JS

`State`/`Bind`/`Action.*` -- ARKlight's first reactivity primitives.
A page can now declare state, read it via `Bind`, and mutate it
through a closed, described set of `Action.*` helpers, all compiled to
real (small, closed-vocabulary) JavaScript -- never an arbitrary
JS/Python expression string handed to the runtime.

## What shipped

- `State(name, initial)` -- page-scoped reactive state, must appear as
  a direct child of `Page(...)`.
- `Bind(name)` -- reads a `State(...)` value into a component.
- `Action.*` registry (`set`, `increment`, `toggle_bool`, ...) for
  `on_click=`.

Everything since built on top of this: computed/derived state, watch
effects, two-way binding, list rendering, and `localStorage`
persistence (all `v0.054`) are all extensions of the `State`/`Bind`/
`Action` shape this release established.
