## What's planned

- Detect-or-create a `.arklight/` directory at the project root, an
  ARKlight-owned, project-local state directory (never `.git/`,
  never source, never configuration).
- A minimal knowledge-format marker (`knowledge_format=1`) so a
  future compiler version can tell whether stored knowledge is
  current, outdated, or safely regeneratable.
- Safe read/write helpers other stages build on.
- Plain-text, human-readable files -- no database requirement.

Deleting `.arklight/` at this stage is a pure no-op: nothing reads it
yet, and nothing in the compiler depends on its presence. That stays
true throughout the ladder -- `.arklight/` enriches project
understanding, it never becomes required for a build to succeed.
