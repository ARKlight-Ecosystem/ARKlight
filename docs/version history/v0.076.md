# v0.076 -- Project Knowledge: diagnostics integration

**Status: PLANNED -- not yet started.** Forward-looking summary,
written ahead of implementation as part of staging
[`docs/Implementation/PROJECT-KNOWLEDGE-ADDENDUM.md`](../Implementation/PROJECT-KNOWLEDGE-ADDENDUM.md)
(stage 6 of 8). Will be updated to reflect actual shipped behavior
once this stage lands.

Sixth rung -- the first stage where Project Knowledge becomes
something a developer running `arklight build` actually sees.

## What's planned

- Surface compact project knowledge in compiler errors.
- Add last-known-good information to diagnostics where it's
  available (e.g. the last revision that built successfully).
- Keep verbose knowledge behind explicit debug output rather than
  ordinary build logs, consistent with the proposal's privacy
  boundary -- no remote URLs or environment dumps in ordinary
  output.

Knowledge surfaced here enriches diagnostics; it never silently
changes generated HTML/CSS/JS output.
