# v0.063 -- JS vocabulary: small new runtime primitives

**Status: PLANNED -- not yet started.** Forward-looking summary,
written ahead of implementation as part of staging
[`docs/Implementation/JS-VOCABULARY-ADDENDUM-v0.070.md`](../Implementation/JS-VOCABULARY-ADDENDUM-v0.070.md)
(stage 3 of 10). Will be updated to reflect actual shipped behavior
once this stage lands.

Third rung -- five small runtime modules, each a day or two of work,
each extending `arklight/backend/js/runtime/*.py` without a new IR
node.

## What's planned

- `reveal`/`lazy` behavior via `IntersectionObserver` -- same shape
  as `scroll-to`, wraps an observer instead of `scrollIntoView`.
- Debounced two-way binding -- extends `Bind.model` to accept the
  existing `MODIFIER_REGISTRY` debounce/throttle tokens, wiring the
  modifier plumbing that already exists for actions into
  `wireModelBinding` too.
- Clipboard **paste** behavior (`navigator.clipboard.readText()`) --
  mirrors `copy.py` almost exactly.
- Geolocation one-shot action (`Action.geolocate(name)` writes
  `{lat, lng}` into state) -- self-contained, no new dependency-graph
  edges.
- `matchMedia`-driven boolean state
  (`State(..., media="(min-width: 768px)")`) -- one `MediaQueryList`
  listener per declared media state.
