# v0.048 -- CSS `@media` queries + structured `<head>`/`<header>` extension

The long-planned "responsive sites without hand-written CSS" release,
landed in two stages: `<head>`/`<header>` metadata support first
(Stage A), then real `@media` query compilation on top of it
(Stage B).

## What shipped

- **Stage A:** `meta`/`links` props on `Page(...)` -- structured
  `<head>` metadata (description, favicon, Open Graph tags, ...)
  without a raw HTML string.
- **Stage B:** `Site.media_query(condition, class_name, rules)`
  (EXPERIMENTAL, gated under `css-media-queries` in
  `docs/Foundational/EXPERIMENTAL-APIS.md`) plus per-node
  `responsive_style={...}`, both compiled to real
  `@media (condition) { .class_name { ... } } ` blocks.

For the full design, see
[`docs/Foundational/DESIGN-NOTES.md`](../Foundational/DESIGN-NOTES.md).
