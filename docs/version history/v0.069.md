# v0.069 -- JS vocabulary: cross-language formatting/case batteries

**Status: PLANNED -- not yet started.** Forward-looking summary,
written ahead of implementation as part of staging
[`docs/Implementation/JS-VOCABULARY-ADDENDUM-v0.070.md`](../Implementation/JS-VOCABULARY-ADDENDUM-v0.070.md)
(stage 9 of 10). Will be updated to reflect actual shipped behavior
once this stage lands.

Ninth rung -- formatting and case-conversion idioms common across
Python/Rust "humanize" and inflection libraries (most tracing back to
Ruby on Rails' inflector), none of which JS ships natively.

## What's planned

- `to_ordinal` -- `1` -> `"1st"`, `2` -> `"2nd"`, etc.
- `humanize_bytes` -- `1536` -> `"1.5 KB"`.
- `humanize_duration` -- seconds -> a `"2h 15m"`-style string.
- `to_snake_case`, `to_camel_case`, `to_kebab_case`, `to_title_case`
  -- pure string-rewrite case converters, no irregular-word problem,
  so despite living in this cross-language batch they're exactly as
  cheap as the earlier catalog stages.
