## JS vocabulary, stage 9 of 10

Ninth rung -- formatting and case-conversion idioms common across
Python/Rust "humanize" and inflection libraries (most tracing back to
Ruby on Rails' inflector), none of which JS ships natively.

### What's planned

- `to_ordinal` -- `1` -> `"1st"`, `2` -> `"2nd"`, etc.
- `humanize_bytes` -- `1536` -> `"1.5 KB"`.
- `humanize_duration` -- seconds -> a `"2h 15m"`-style string.
- `to_snake_case`, `to_camel_case`, `to_kebab_case`, `to_title_case`
  -- pure string-rewrite case converters, no irregular-word problem,
  so despite living in this cross-language batch they're exactly as
  cheap as the earlier catalog stages.

## `Provider`, stage 5 of 6: `arklight search` integration

Extends `arklight search`'s existing schema-lookup reflection to a
registered `Provider`'s capability contract, the same "look something
up without opening a file" convenience `SCHEMA` already gets for
components.

### What's planned

- `arklight search <provider-name>` prints the declared capability
  contract (name, capabilities, DOM hooks/state keys), reusing the
  existing typo-tolerant fallback machinery rather than a second,
  parallel fuzzy-matcher.
