# v0.0431 -- Emergency patch: unrouted-attribute build warning

A small, out-of-band patch between `v0.043` and `v0.048`: `arklight
build` now warns at build time if a site uses `srcset`/`poster`/
`action`/`formaction` in a way the HTML backend doesn't actually route
to output -- catching a class of silent, browser-only failure before
it ships.
