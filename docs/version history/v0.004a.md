# v0.004a -- CLI scaffolding

`arklight new <name> --template simple|production` -- a new project
in one command instead of hand-writing the first `site.py` from
scratch every time.

## What shipped

- `arklight new`, with two starting templates: `simple` (one file) and
  `production` (a `components/` directory, `assets/`, and the
  conventional layout every later feature -- `assets/` auto-copy,
  `arklight.config.py` discovery -- assumes).
