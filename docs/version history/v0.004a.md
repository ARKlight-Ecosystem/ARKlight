# v0.004a -- CLI scaffolding

`arklight new <name> --template simple|production` -- a project
generator, so starting a new ARKlight site no longer means copying
files by hand. Originally tracked as part of a combined "v0.004"
heading alongside the `@media`/`<head>` work; split out as its own
`v0.004a` once it shipped well ahead of the other two pieces (which
went on to become v0.048).

## What shipped

- `arklight new <name> [--template simple|production] [--dir PATH]`
  -- new CLI subcommand (`arklight/cli/scaffold.py`, wired in as
  `_cmd_new` in `arklight/cli/main.py`).
- Two built-in templates (`arklight/cli/templates/simple.py` and
  `.../production.py`), each returning a plain
  `dict[relative_path, contents]` -- templates never touch the
  filesystem themselves; `scaffold.py` owns validation and writing.
- Project-name validation: rejects empty names, `.`/`..`, and any
  name containing a path separator (blocks a name like `"../evil"`
  or `"a/b"` from writing outside the intended destination
  directory).
- `--dir PATH` to choose where the new project directory is created,
  instead of always using the current working directory.
