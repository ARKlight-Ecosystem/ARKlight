# v0.070.0 -- Alpha catch-up: user-defined components, JS vocabulary ladder, Provider, Platform API IR, preamble system, Rei narrator, ACC hook

Brings `main`'s **documentation** up to parity with `alpha`'s
`0.070.0`-equivalent state (`docs/Foundational/` in full, plus this
directory's own coverage through `alpha`'s `v0.070.md`). This is a
**docs-only** release -- the underlying code for each feature below
still needs its own sync pass onto `main`; see
[`docs/syncing main with alpha branch/MAIN TO ALPHA V0.070.0.md`](<../syncing main with alpha branch/MAIN TO ALPHA V0.070.0.md>)
for that plan. Android and Desktop packaging, and `arklight deploy`,
are **explicitly out of scope** -- not carried over code-wise, and
flagged as alpha-only in the docs themselves rather than silently
included.

## User-defined, reusable components (v0.060)

A plain Python render function can become a real, named component
type the compiler understands: `component(props=...)` with a checked
props contract, typo diagnostics, optional default styling,
experimental per-backend rendering, and component-owned reactive
state. Full reference:
[`docs/Foundational/USER-DEFINED-COMPONENTS.md`](../Foundational/USER-DEFINED-COMPONENTS.md).

## JS vocabulary expansion, 10 rungs (v0.061-v0.070)

A ten-stage ladder of closed-vocabulary JS additions: math siblings,
string casing/comparison predicates, small runtime primitives, math
derivations, string derivations, predicates, list-scalar derivations,
cross-language numeric batteries, cross-language formatting/case
batteries, and the capstone (`pluralize`, `random_int`). Every entry
is still a fixed, compiler-validated vocabulary member -- no `eval`,
no arbitrary expressions.

## `Provider`: external-service declarations (v0.065-v0.070, shipped in full)

A barebones interface for declaring external services a site depends
on -- capability vocabulary (plus a `custom:` escape hatch), external
script loading, and `arklight search` integration. Six-rung ladder,
all shipped. Design record:
[`docs/Foundational/PROVIDER-SDK.md`](../Foundational/PROVIDER-SDK.md).

## Platform API IR, stage 1 of 2 (v0.065)

`PlatformAPI.notify`/`.clipboard_write` as a backend-independent,
versioned interface layer the compiler owns -- Web reference
implementation shipped; native Android/Desktop implementations remain
unscheduled. Design record:
[`docs/Foundational/PLATFORM-APIS.md`](../Foundational/PLATFORM-APIS.md).

## Preamble system: `# include` / `# define`

Real preamble directives replace the old `from arklight import *`
reach -- every Python file gets the same, explicit, whole-repo name
resolution.

## Rei, the compiler narrator (`--narrate`)

Structured, `[Rei]`-tagged build narration for compiler stage events
-- an original implementation, not a chatbot; fixed-format strings
with named groups, not free text.

## ACC capability-discovery hook

`arklight/capabilities.py` -- the `arklight.capabilities` entry-point
contract that lets an installed ARKlight Component Collection package
advertise itself, used today by SBOM generation. Design record:
[`docs/Foundational/ACC-CAPABILITIES.md`](../Foundational/ACC-CAPABILITIES.md).

## Repo-safety tooling

Pre-write asset and link gates (fail the build on a broken local
reference before it ships), an opt-in `overdrive` escape hatch for
references that can't be verified at build time, and SBOM generation.

## Explicitly not in this release

- **Android and Desktop packaging backends.** Both are real, shipped
  subcommands on `alpha` (`arklight android scaffold`, `arklight
  desktop scaffold`/`build`), but need more time before landing on
  `main`. `docs/Foundational/CLI-REFERENCE.md` documents them anyway
  (it's a whole-project reference, not a `main`-only one) with an
  explicit "alpha-only so far -- not yet on `main`" note on each.
- **`arklight deploy`.** Same treatment -- documented, not shipped
  here.
- **`docs/Backends/`, `docs/Far Future Concern/`,
  `docs/Implementation/`, `docs/Proposals/`, `docs/reference/`.**
  Working-reference and staging folders, `alpha`-only by design (see
  `docs/README.md`'s folder guide). Any Foundational-doc link that
  would point into one of these now uses a full
  `github.com/.../blob/alpha/...` URL instead of a relative path,
  since `main`'s tree doesn't carry the target.

## Version numbering

Continues the `MAJOR.MINOR.PATCH` scheme `v0.54.0` introduced. This
release's number matches `alpha`'s own `pyproject.toml` version
(`0.070.0`) because `alpha` has since adopted the same scheme `main`
started -- see `CHANGELOG.md`'s `[Unreleased] -- Version scheme
migrated...` entry on `alpha` for why (a `PEP 440`
leading-zero-normalization hazard in the old `0.0NN` milestone
numbers). Matching the number here doesn't imply matching code state;
see the "Explicitly not in this release" section above.
