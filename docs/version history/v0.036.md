# v0.036 -- ARK Bundle spec v1

`arklight pack` -- collapse a whole built site into a single
distributable `.ark` file, instead of shipping a folder of loose HTML/
CSS/JS/asset files.

## What shipped

- The ARK Bundle format itself (`arklight/packer/bundle.py`) and the
  `arklight pack` CLI command.

Sealing (encryption by default) followed immediately after in
`v0.037`.
