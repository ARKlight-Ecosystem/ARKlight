# v0.036 -- ARK Bundle spec v1

Package a built site into a single, self-contained file.

## What shipped

- `arklight pack <build-dir> -o site.ark` -- packages an existing
  `arklight build` output directory into an `.ark` file: an
  HTML/ZIP polyglot. The same bytes are both a directly-renderable
  HTML document (double-click / open in a browser, no unzip step, no
  temp files, no local server) and a valid ZIP archive (any archive
  tool extracts the original build output).
- `arklight.packer.bundle.pack(build_dir, output_path) -> PackResult`,
  the underlying Python API.

## Scope of this first version

Only `.html` / `.css` / `.js` files are packed -- an `assets/` folder
with images, audio, or video is intentionally left out and reported
as skipped rather than silently dropped. Asset carry-over landed in
[v0.037](./v0.037.md).
