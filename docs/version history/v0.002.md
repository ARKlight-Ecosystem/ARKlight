# v0.002 -- CSS

Every generated site gets real styling, with zero CSS written by
hand.

## What shipped

- A CSS backend generating a default `styles.css`: typography,
  spacing, buttons, links, and `.nav` / `.card` / `.muted` utility
  classes.
- The build pipeline now runs a list of backends by default
  (`[HTMLBackend(), CSSBackend()]`) and merges their output;
  customizable via `build(..., backends=[...])`.
- `class_name` and `style` (dict) props on any component, rendered
  as the HTML `class` attribute and an inline `style` attribute.
- `arklight build` now opens the built site in your default browser
  automatically (`--open`, the default, or `--no-open` to skip it).

## Notable fixes

- Internal links (`Link(..., href="/about")`) now compile to real
  relative file paths instead of root-absolute routes -- previously,
  opening `dist/index.html` directly sent `href="/about"` to the
  filesystem root instead of `dist/about.html`.
