# v0.002 -- CSS (default stylesheet)

A site now gets real, sensible default styling for free -- no CSS
written by hand required to look like more than unstyled browser
defaults.

## What shipped

- The CSS backend (`arklight/backend/css/`), run alongside the HTML
  backend over the same Website IR.
- A base stylesheet applied automatically to every build.

Custom class authoring, `@media` queries, and per-node style overrides
all came later (`v0.042`, `v0.048`) -- this release is the base layer
they build on.
