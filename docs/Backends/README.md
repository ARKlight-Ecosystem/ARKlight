# Backends

## Overview

Design and staging docs for individual output/packaging backends
(Android, desktop) and proposals for backends under consideration.

**These are working references only, nothing more.** Each file exists
to guide an in-progress or proposed piece of work. Once that work is
finished and its outcome is captured elsewhere (the `CHANGELOG.md`,
`PROGRESS.md`, or a Foundational doc), the file has served its purpose
and will be removed — it is not meant to be kept as permanent
documentation.
